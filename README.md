# Site ONG Mãos Solidárias

Página institucional de uma ONG fictícia, desenvolvida como atividade acadêmica do curso de Engenharia de Software (UNICID).

**Acesse o site:** https://kauanyassis1-stack.github.io/site-ong-maos-solidarias/

## Conteúdo

- Apresentação da ONG e da sua atuação em educação, inclusão digital e apoio a famílias
- Informações de contato
- Layout responsivo, que se adapta ao celular

## Tecnologias

- HTML5 semântico (`header`, `main`, `section`, `footer`)
- CSS3 com variáveis de cor

## Estrutura

```
site-ong-maos-solidarias/
├── index.html
├── imagens/
│   └── ong.svg
└── README.md
```

## Como abrir

Baixe o repositório e abra o arquivo `index.html` no navegador.
